OSINT+ // USERNAME — maigret ONLINE
MAIGRET
Search username across 2,500+ websites and social networks.
MULTICHECK
Cek username secara serentak di 15 platform — GitHub, Reddit, Twitter, YouTube, Twitch, Telegram, dan lainnya.
GITHUB OSINT
Profile, repositories, email dari commit history, followers, dan metadata akun GitHub.
GitHub API · opsional: set GITHUB_TOKEN di .env untuk rate limit lebih tinggi
IP GEOLOCATION
Lokasi, ISP, ASN, timezone, dan deteksi VPN/Proxy/Hosting dari alamat IP.
Source: ip-api.com · gratis, tanpa API key
HOLEHE
Check which services have an account linked to an email address.
EMAIL OSINT
Email intelligence — validasi format, disposable check, MX records, Gravatar, dan investigation links.
Source: disify.com · gravatar.com
IPINFO — PHONE
Phone number lookup: country, carrier, line type, timezone.
Include + and country code: +62 for ID, +1 for US, +44 for UK
WHOIS
Domain registration, DNS, IP, SSL certificate analysis.
IGINFO
Instagram public profile OSINT — followers, posts, bio, user ID.
TOUTATIS
Deep Instagram OSINT — phone number, email, exact location from business accounts.
Session ID diambil dari .env secara otomatis
HIBP — EMAIL
Check if email was exposed in data breaches and paste sites.
API key required — set HIBP_API_KEY in .env
HIBP — PASSWORD
Check if a password was exposed in known data breaches using k-anonymity (no key needed).
Password is hashed locally. Only first 5 chars of SHA-1 are sent.
TELCEK
Check phone number registration on Telegram, WhatsApp, Viber, and other messengers.
EMAIL HEADER ANALYZER
Parse raw email headers — trace hop-by-hop IPs, detect spoofing, DKIM/SPF/DMARC status.
Pure Python parser · no API needed
Paste only the headers section (before the email body)
DNS DEEP LOOKUP
Query semua DNS records: A, AAAA, MX, NS, TXT, CNAME, SOA, CAA + DMARC, SPF, DKIM selector scan.
dnspython · ip-api.com untuk geo IP
PASTE / LEAK SEARCH
Cari username atau email di paste dumps dan breach database.
psbdmp.ws · HIBP (email, butuh key) · IntelX (butuh key) · GitHub (butuh token)
Tambahkan HIBP_API_KEY + INTELX_KEY + GITHUB_TOKEN di .env untuk hasil lebih lengkap.
